### **Qué es una partida**

Una partida es una operación individual de cobro o pago que impacta directamente en el cashflow de la empresa.

### **Cómo crear una partida básica**

Desde el apartado **Tesorería**, haz clic en **Crear partida** y selecciona la versión básica.

Introduce los datos principales de la partida:

- Nombre libre\


- Tipo de partida (entrada o salida)\


- Categoría\
  \


Configura la conciliación de movimientos definiendo condiciones como palabras clave o importes.

Activa la conciliación automática si quieres que los movimientos futuros se concilien solos.

Por último, revisa o crea la previsión y guarda la partida

<Callout kind="alert" collapsed="false">
  Opción de bolsa (Para gastos variables) Previsiones que no se tienen por qué cumplir.
</Callout>

## Automating Bank Reconciliations

Match transactions effortlessly to keep your books accurate.

### Setup Process

<Steps>
  <Step title="Connect Bank" icon="link" title-type="p">
    Link your bank accounts via secure API or CSV upload.

    ```csv
    Date,Description,Amount,Reference
    2024-01-15,Client Payment,1500.00,INV-123
    2024-01-16,Sales Receipt,2500.50,INV-124
    ```
  </Step>

  <Step title="Map Categories" icon="settings" title-type="p">
    Assign rules for automatic categorization.
  </Step>

  <Step title="Run Reconciliation" icon="play" title-type="p">
    Orama matches 95%+ of transactions automatically.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Use custom rules for recurring transactions to boost accuracy.
</Callout>

## Generating Automatic Financial Forecasts

Orama analyzes your data to project cash flows.

<CodeGroup show-lines="true" tabs={[]}>
  ```javascript
  // Monthly forecast config
  {
    "horizon": 12,
    "model": "arima",
    "dataSource": "bank_statements"
  }
  ```

  ```javascript
  // Quarterly forecast config
  {
    "horizon": 4,
    "model": "prophet",
    "seasonality": true
  }
  ```
</CodeGroup>

Forecasts update daily with new transactions.

## Creating What-If Scenarios

Simulate changes to evaluate impacts.

### Scenario Workflow

1. Duplicate your base forecast.

2. Adjust variables like expenses or revenue.

3. Compare outcomes side-by-side.

| Scenario    | Revenue Change | Expense Change | Projected Balance |
| ----------- | -------------- | -------------- | ----------------- |
| Base        | 0%             | 0%             | €50,000           |
| Optimistic  | +10%           | -5%            | €65,000           |
| Pessimistic | -5%            | +10%           | €35,000           |

<Expandable title="Advanced Scenario Tips" default-open="false">
  Use sensitivity analysis for key variables like interest rates.
</Expandable>
