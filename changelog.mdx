## Recent Releases

Stay current with Orama's latest enhancements in cash flow forecasting, bank reconciliations, and reporting tools.

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added AI-powered cash flow predictions using historical data and market trends.
- Introduced multi-currency support for international transactions.
- New customizable dashboard widgets for key metrics like liquidity ratios.

## Improvements

- Enhanced bank sync speed by 40% with optimized API polling.
- Improved report export options including PDF and Excel with custom branding.

## Bug Fixes

- Fixed reconciliation mismatches for SEPA transfers.
- Resolved intermittent dashboard refresh issues during high-load periods.

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete overhaul of the forecasting engine with scenario planning tools.
- Integrated webhook notifications for payment events.
- Added role-based access controls for team collaboration.

## Breaking Changes

- Updated API endpoints for forecasts: Use `/v2/forecasts` instead of `/forecasts`.
- Deprecated legacy report formats; migrate to new schema.

## Bug Fixes

- Corrected rounding errors in multi-account consolidations.
- Fixed export failures for large datasets over 10,000 transactions.

</Update>

## Upgrade Instructions

To upgrade Orama, follow these steps in your dashboard.

<Steps>
  <Step title="Check Current Version" icon="info">
    Navigate to **Settings > About** to view your installed version.
  </Step>
  <Step title="Review Changelog" icon="book-open">
    Scan this page for breaking changes relevant to your setup.
  </Step>
  <Step title="Update" icon="download">
    Click **Update Now** in the dashboard. The process takes under 5 minutes.
  </Step>
  <Step title="Verify" icon="check-circle">
    Test key workflows like bank sync and forecasts post-update.
  </Step>
</Steps>
